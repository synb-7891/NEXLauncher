# NEX Launcher 新版界面（WebView2 混合版）使用说明

## 这是什么

把之前做的新版界面（PCL2 式启动体验 + Verse 式自由拖拽开始页面 + 皮肤站 / 百宝箱 / 安全防护）
**正式嵌入了启动器本体**。你的启动器现在有两套界面，共用同一份账号、版本和设置：

- **新版界面**（默认启动）：自由拖拽首页、皮肤站、百宝箱、安全防护四页
- **经典界面**（原有 WPF 界面）：游戏版本 / 模组管理 / 资源下载 / 账号 / 设置 等全部功能页

## 界面怎么切换

| 动作 | 结果 |
|---|---|
| 启动器打开 | 直接进新版「开始页面」 |
| 新界面里点 **游戏版本 / 模组 / 资源下载 / 账号 / 设置** | 切到经典界面的对应功能页（功能 100% 不变） |
| 新界面里点头像 | 打开经典界面「账号」页 |
| 经典界面左侧点 **首页** | 回到新版开始页面 |
| 皮肤站 / 百宝箱 / 安全防护页顶部的 **打开完整功能页** | 切到对应的经典功能页 |

## 新版界面里的真实功能（不是演示）

- **启动游戏**：走启动器真实启动流程（版本没装会提示先下载），与侧栏启动按钮同一套逻辑
- **主题切换**（设置页 6 张色卡）：同步改原生界面的 UiPalette，两套界面一起换肤
- **安全防护数据**：守护进程 PID / 心跳 / 已守护时长、五道防线开关状态、诱饵文件在位情况、
  真实安全事件日志 —— 全部实时读取 `AppData\Local\NEXLauncher` 下的数据文件
- **账号 / 版本 / 内存**：读取当前登录会话、已安装版本（含加载器类型）和内存设置
- **窗口控制**：顶部原生标题栏，可拖动、双击最大化、最小化 / 最大化 / 关闭

## 想回到旧界面？

环境变量 **`NEX_LEGACY_UI=1`** 启动即可完全跳过新版界面（经典界面原样）。
例如 PowerShell：`$env:NEX_LEGACY_UI="1"; & "D:\NEXLauncher\dist\NEXLauncher-win-x64\NEXLauncher.exe"`

## 常见问题

- **启动后还是老界面**：系统没装 WebView2 Runtime 时会自动回退（会记录到
  `AppData\Local\NEXLauncher\crash.log`）。Win10/11 一般自带；装一下
  「Evergreen WebView2 Runtime」即可。
- **主题换完经典界面没变**：经典页面是构建时读色的，切到对应页面会自动按新配色重建。
- **拖拽位置保存在哪**：浏览器 localStorage（WebView2 用户目录），换皮肤主题不影响。
