Security

五道防线，从“发现”到“清除”

5

FAQ

常见问题

双击后没有任何反应，或者被杀毒软件拦截怎么办？

因为启动器是自包含单文件程序、且带安全监控模块，个别杀毒软件会误报。请在杀毒软件中把解压目录加入信任；如果 Windows 提示「已保护你的电脑」，点击「更多信息 → 仍要运行」。程序不含任何联网上传、后台上传行为，可自行核对源码。

需要先安装 Java 吗？

不需要。启动器会自动选择并下载对应版本所需的 Java 运行时，安装完成后可直接启动游戏。你也可以在「设置 → Java」里手动指定本机已安装的 Java 路径。

可以用微软正版账号登录吗？

可以。打开「账号 → 微软登录」，会弹出独立的登录窗口走官方 OAuth 授权，登录成功后令牌会被安全保存，下次启动自动免密登录，无需反复输入密码。

安全防护会不会误删我的正常文件？

拦截采用评分制：双扩展名 +55、仿冒系统进程 +60、临时目录运行 +20、隐藏属性 +25，累计达到 55 分才处置，且只有可执行文件类型才会进入判定。默认是「移入隔离区」而不是永久删除，随时可以在隔离区还原。

支持哪些系统？

当前正式支持 Windows 10 / 11（64 位）。Windows 7 及以下版本的系统组件较旧，无法保证 WebView2 渲染正常，暂不支持。
